# Проверки перед сдачей

Порядок: контент → хост → устройства → глазами. Каждый шаг — скрипт с PASS/FAIL; FAIL либо чинится, либо объясняется в итоговом отчёте как осознанное решение пользователя.

## 1. Контент — `compare.mjs`

```
node <skill>/scripts/inventory.mjs index.html --out content/result-inventory.json
node <skill>/scripts/compare.mjs <источник> content/result-inventory.json --allow content/ui-strings.json [--link-map content/link-map.json] [--no-ids]
```
- Источник: `content/content.json` (pdf) или `content/inventory.json` (html/webpage).
- Проверяет: весь исходный текст есть в результате (вкл. скрытый, тултипы, aria, meta); в результате нет текста, которого нет в источнике (кроме UI-строк; допускается склейка двух соседних исходных строк, например подпись + уточнение); каждое число результата есть в источнике; заголовки в исходном порядке; ссылки (с учётом замен); `id` и `data-*`; количество компонентов (информационно); alt (информационно — намеренно меняется).
- `WARN … match only when spaces are ignored` — потерян или лишний пробел (часто внутри `<span>` без пробела между ними). Проверь по скриншоту.
- Инвентаризация результата — по `index.html` без запуска JS (счётчики не поймаются на середине). Для проверки опубликованной страницы — URL и `--js`.

## 2. Хост — `hostsim.mjs`

```
node <skill>/scripts/hostsim.mjs dist/index.html [--header ".site-header"] [--widths 1440,390]
```
Страница внутри srcdoc-iframe со стилем хоста. Проверяет: колесо мыши прокручивает страницу; хедер остаётся наверху и переключается в «прокрученное» состояние; прогресс двигается; **каждая** якорная ссылка доводит цель под хедер и не перезагружает фрейм; нет ошибок JS. `WARN relative asset reference(s)` на локальной версии — нормально: в srcdoc относительные пути резолвятся от страницы хоста и дадут 404, поэтому финальный прогон — на версии с CDN (`dist-relayto/`), там предупреждения быть не должно. `FRAME NAVIGATED` = якорь без JS-обработки → подключи `microsite.js`. Хедер уехал (`top=-1900`) = нет `height: auto !important` на html/body.

## 3. Устройства — `qa.mjs`

```
node <skill>/scripts/qa.mjs dist --allow-hosts cdn-3.relayto.com[,<хост видео>] [--only iphone,desktop-1440]
```
12 профилей (Chromium / WebKit=Safari / Firefox; 1920…320, планшеты, landscape). На каждом: скролл «как читатель» с включённой анимацией, скриншоты верха и всей страницы, проверки — нет горизонтального скролла (с указанием виновных элементов), все картинки загрузились, нет ошибок JS, нет сторонних запросов до действий пользователя, все `.reveal` проявились, на мобильных тап-таргеты ≥ 40px и текст ≥ 12px, на десктопе видимое кольцо фокуса.

Ожидаемые исключения (объясни в отчёте, не «чини»): видео, которое по решению пользователя стартует само при попадании в экран (Westinghouse YouTube) — сторонние запросы до клика; фоновое hero-видео с внешнего хранилища — добавь хост в `--allow-hosts`. Мелкие тап-таргеты-хотспоты на схеме — допустимы, если рядом есть список/аккордеон с теми же действиями.

## 3½. Остатки исходника

Для reskin: ни одного шаблонного цвета и ни одной ссылки на старые ассеты в итоговом файле:
```
grep -oiE "#6366f1|#4f46e5|#f59e0b|microsite\.relayto\.com|uikit" dist/index.html | sort | uniq -c
```
(подставь цвета и хосты своего исходника). Пустой вывод — PASS.

Если оба языка из источника лежат в DOM, `compare.mjs` проверяет их вместе — UI-строки в `ui-strings.json` заводятся на обоих языках. Если второй язык подставляется словарём: переключи его в браузере, сними инвентаризацию (`inventory.mjs <url> --js` после клика или отдельной версией) и проверь, что каждая строка словаря применилась и не осталось непереведённых блоков.

## 4. Глазами

- Скриншоты результата рядом с `reference/source` (структура совпадает) и `reference/site` (стиль узнаваем как сайт клиента).
- Состояния: каждая вкладка, аккордеон, меню, лайтбокс, видео-фасад, тултип.
- Тексты на фото — контраст AA (оверлей, если нет).
- Проверь печатью «во весь экран» 1920 и самый узкий 320 — там ломается чаще всего.

## Итоговый отчёт пользователю

1. Что сделано по секциям (кратко: компонент → как подан).
2. Таблица замен изображений: слот → было → стало (источник на сайте) → alt.
3. UI-строки и замены ссылок.
4. Решения по открытым вопросам из шага 3.
5. Результаты проверок (compare / hostsim / qa) и осознанные исключения.
6. Поставка: какой режим, где `dist/index.html`, список файлов для хаба / `asset-urls.json`, как посмотреть локально: `node <skill>/scripts/serve.mjs dist`.
