# Инпут: страница существующего сайта

Эталон — Westinghouse eVinci Microreactor: страница корпоративного сайта → standalone-микросайт с тем же контентом, в том же стиле, с локальным навбаром и enrichment. Обычно источник контента и сайт клиента — один и тот же сайт.

## Шаги

1. Сохрани исходную страницу: HTML (`reference/source/original.html`) и отрендеренный DOM после JS (`rendered.html`), скриншоты 1440 / 768 / 375 (viewport и full page).
2. Найди селектор основного контента (без шапки, мега-меню, сайдбара, футера сайта) и сними инвентаризацию только с него:
   ```
   node <skill>/scripts/inventory.mjs https://client.com/page/ --scope "main .content" --out content/inventory.json
   ```
3. Дополнительно составь `content/content-map.md` — контент **дословно, в порядке источника** (заголовки, абзацы, списки с вложенностью, картинки с исходными URL, видео, CTA, ресурсы со ссылками). Это удобная для человека карта; проверка идёт по `inventory.json`.
4. Что обычно удаляется (подтверди на шаге 3): трекинг (GTM, аналитика, BrightEdge-мета), поиск, мега-меню, хлебные крошки, сайдбар раздела, модалки сайта (Global Directory), блоки «Also of interest», футер — заменяется упрощённым в стиле сайта. Плюс то, что пользователь назвал сам.
5. Ассеты — с этого же сайта, в **исходном разрешении** (CMS отдаёт ресайзы через параметры `?width=…&rmode=…`, `?fit=…`; `capture_site.mjs` пытается восстановить оригинал). Видео героя — тоже с сайта, если оно там есть (в Westinghouse — mp4 в двух размерах 1920/960 с постерами).

## Локальный навбар

- Пункты — смысловые секции страницы, короткими подписями (подписи — UI-строки, если их нет в тексте дословно). Westinghouse: Overview · Key Benefits · Heat Pipe · Environmental · Passive Safety · Applications · Technology Hub · Resources.
- Логотип слева ведёт наверх; CTA справа — в стиле primary-кнопки сайта.
- Прозрачный над hero, сплошной после прокрутки; прогресс чтения; scroll-spy; бургер ниже ~1200px, если пунктов много (Westinghouse) или ~992px (Veriff).
- Всё это уже есть в рантайме — разметка в комментарии к `microsite.js`.

## Внешние ресурсы

- PDF-брошюры и data sheets: если у клиента есть RELAYTO-версии этих документов, ссылки заменяются на них и открываются в лайтбоксе поверх страницы (`<a data-lightbox>`); Ctrl/Cmd-клик открывает новую вкладку. Замены — в `content/link-map.json`, текст ссылок не меняется.
- Виртуальный тур / внешние приложения — тоже через лайтбокс, если сайт позволяет встраивание; иначе новая вкладка.
- YouTube: фасад с постером; nocookie; при `file://` открывать youtube.com (там «Error 153» без referrer). В Westinghouse видео стартует само без звука при попадании в экран — это было решение пользователя; по умолчанию — по клику.

## Проверка

`compare.mjs content/inventory.json content/result-inventory.json --link-map content/link-map.json --no-ids` (id сайта не нужно сохранять — страница собирается заново). Количество компонентов будет отличаться — это ожидаемо при enrichment; важно, что каждый исходный текст на месте.
