# Инпут: готовый HTML (страница коллеги / генератор RELAYTO)

Эталон — UAENO: single page на UIkit 3 + DM Sans, шаблонная палитра indigo/amber, ассеты на `microsite.relayto.com`, атрибуты `data-ai-slot`. Режим по умолчанию — **reskin 1:1**: контент, структура, порядок секций, типы компонентов и поведение не меняются; меняется дизайн и все картинки.

## Шаги

1. Положи файл в `source/index.html`. Инвентаризация:
   ```
   node <skill>/scripts/inventory.mjs source/index.html --out content/inventory.json
   ```
   По умолчанию JS страницы не выполняется — сырой DOM уже содержит скрытые вкладки и аккордеоны, а счётчики не поймаются на середине анимации. Скрипт сообщит, сколько блоков сейчас скрыто, сколько тултипов и какие `data-*` есть.
2. Скриншоты исходника в `reference/source/` на 1440 / 768 / 375 **в каждом состоянии**: каждая вкладка, каждый пункт аккордеона открытым, открытое мобильное меню, наведённый тултип. Это эталон структуры для сравнения в конце.
3. Перечисли компоненты и их поведение (из разметки и библиотеки): sticky/transparent хедер, offcanvas, tabs (с анимацией?), accordion (один открыт? какой открыт по умолчанию?), tooltips, timeline, stat-карточки, quote-карточки, чипы, alert, CTA-band, анимация `.reveal`. Поведение воспроизводится точно.
4. Слоты изображений: где, смысл (что изображено сейчас или что должно быть), пропорции. Пустые слоты с заглушкой (`data-ai-slot` с градиентом) — отметь отдельно.
5. Всё, что выглядит странно, **не исправляй, а внеси в отчёт**:
   - порядок пунктов навбара не совпадает с порядком секций, или секции нет в навбаре (в UAENO: About стоит раньше Ensemble, хотя на странице наоборот; Journey в навбаре отсутствует);
   - захардкоженные инлайн-цвета шаблона (`style="background:linear-gradient(135deg,#6366f1…)"`, `rgba(245,158,11,.12)`, `#78350f`) — их придётся заменить токенами;
   - пустые слоты, битые ссылки, ссылки «#».

## Правила reskin

- **Не меняется:** весь текст, включая скрытый; порядок секций; иерархия заголовков; количество карточек/пунктов/цитат/чипов; типы компонентов (tabs остаются tabs, accordion — accordion); все `href`; все `id` и `data-*`; пункты навбара и их порядок; meta; aria.
- **Меняется:** визуал (токены и компоненты сайта клиента), декор, изображения, alt под новые изображения.
- **Изображения исходника заменяются полностью** ассетами сайта клиента. Ни одного URL с `microsite.relayto.com` и ни одного файла исходника в результате. Контейнер слота с его `data-ai-*` атрибутами сохраняется, пропорция — тоже.
- Текстовый логотип (в UAENO — «UAE<span>NO</span>») заменяется реальным SVG-логотипом клиента; `aria-label` ссылки сохраняется.
- Шаблонные цвета (#6366f1, #4f46e5, #f59e0b и т.п.) не должны остаться нигде — ни в CSS, ни в инлайн-стилях.

## Библиотека исходника (UIkit и подобные)

Выбор выносится на шаг 3:
- **Убрать библиотеку** и воспроизвести поведение на рантайме скила + своём JS (чище, без CDN, стиль не «протекает»). Иконки библиотеки → inline SVG в стиле сайта.
- **Оставить JS библиотеки**, полностью перекрыв её стили — если страница потом обрабатывается генератором RELAYTO, который ожидает её разметку.

В любом случае якорные ссылки должны идти через рантайм (`microsite.js`), иначе в RELAYTO они перезагружают фрейм — см. `relayto.md`.

## Проверка

`compare.mjs content/inventory.json content/result-inventory.json` должен пройти без `--no-ids`. Alt сверяется отдельно: он намеренно меняется — в итоговом отчёте таблица «слот → было → стало → новый alt». Поведение проверяется кликами: каждая вкладка, каждый пункт аккордеона (открыт только один, если так было), offcanvas на 375, тултипы, все якоря.

## Как это прошло на UAENO (для ориентира)

- UIkit убран, поведение переписано на чистом JS: tabs с fade, аккордеон (`multiple: false`, первый открыт), offcanvas справа с оверлеем, тултипы на hover и фокусе (`uk-tooltip` → `data-tooltip`, текст тот же), якоря через JS.
- Все `id` и `data-ai-*` на месте; текстовый «UAENO» заменён SVG-логотипом с сайта (отдельно для шапки и футера).
- Картинки исходника заменены фото из медиатеки сайта: hero (оркестр на сцене, набор 480–2000 webp), дебют (фото из статьи про Zayed National Museum, конвертировано из avif), тур (репетиция скрипачей); по согласованию добавлены фоновое видео в hero, фото-плитки в Ensemble и во вкладках, фото в CTA.
- По согласованию добавлен переключатель EN ↔ AR (см. `enrichment.md`, «Второй язык»).
- Проверка скилом после сдачи: весь исходный текст на месте, числа, заголовки, ссылки, `id`, `data-*` — PASS; «лишними» оказались только две UI-строки переключателя языка; `hostsim` — PASS.
